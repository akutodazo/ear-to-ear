### 0-3. 順位の丸
直径 30px、縁 2px の `--brand`。**下書きは破線**、**確定は実線で地を `--brand`・数字は白**。順位なしは点線。地図の上も一覧も同じ丸。

### 0-4. 画面の切り替えと操作
- 下の帯で 地図／見比べる／刈る順番（いまの画面は `--brand-soft` の地）。11-04 の §7-3「シートの 3 段」は使っていない
- 見比べる: 2 枚の写真の**境目を指で動かす**（上下 2 つの窓／重ね）。上の段の札は流れ去り、写真だけが上に残る
- 並べ替え: **行を長押しでつかむ**と、ほかの行がよけて並べ替わり、丸の番号も変わる（音楽のプレイリストのように）。▲▼ も残す。つかんでいる行は少し浮かせる
- 取り消し・確定・並べ直しは 2 段で確かめる。結果は押した所の近くに 1 行
- 判断を残す: 開くと下に「記録する」「やめる」を固定。上の段は小さくなる

### 0-5. 段の見た目（見比べるの本文）
「昨年の同じ頃」「判断の履歴」「引き継ぎメモ」は同じ段: 上に細い線、見出しは 0.85rem 太字の `--text-2`。枠で囲まない。中身が無い段は見出しごと出さない（メモは「作る」を出すため残す）。

### 0-6. LINE に 1 枚の絵（`src/lib/order-image.ts`）

## 1. 原則（5 つ）と、やらないこと

| # | 原則 | 何を意味するか | 出典 |
|---|---|---|---|
| P1 | **場所が先、文字は札で** | 画面の中心は航空写真の上の輪郭。番号・名前・日付・状態は輪郭に付く**札**（短い文字の面）で出し、文章の説明は書かない | 依頼文の条件 1・2、`design-concept.md` §1 前提 1 |
| P2 | **関係を見せる** | 1 つの畑の情報より、**目安 ↔ この畑**、**仮 ↔ 確定**、**今年 ↔ 昨年** の関係を並べて見せる。比べる 2 つは必ず同じ大きさ・同じ並び | 依頼文（早い畑との差）、条件 4・6・7 |
| P3 | **人の判断は面、AI は丸、未確認は塗らない** | 状態は色でなく**形**で分ける。人の判断は輪郭の中の塗り、順番は番号の丸（破線＝仮、実線＝確定）、未確認は塗らずに文字。色は補助 | 条件 3、`design-concept.md` §1 前提 4 |
| P4 | **日なたでも手袋でも** | 航空写真の上でも読めるよう、文字は暗い面の上に白、輪郭は白と黒の二重線。押せる所は 56px 以上。本文 18px | 既存 `globals.css` の冒頭、WCAG 2.2 |
| P5 | **動くのは応答のときだけ** | シートの開閉、並べ替え、「送れた」。自動で動く飾りは無い。地図の下地も動かない | 既存 D8、`prefers-reduced-motion` |

**やらないこと**（理由は `design-concept.md` §1・§5）: 升目の一覧をトップに置く／集計の数字のタイル／影・ぼかし・発光／グラデーションの面／アイコンだけのボタン／絵文字／トースト／モーダル／ダークモード（航空写真の上は常に暗い面＋白文字で、ページ側はライト固定）／写真から成熟度・水分・収穫予定日を出す文（K11・K16）／未確認を「収穫不可」と書く／順番を結ぶ線（道順に見える）。

### 1-2. 嫌われるデザインの一覧（11-05 本人の追加資料。「しないこと」として使う）
出どころ: Zenn「嫌われるデザイン」の年代別の整理（https://zenn.dev/blackmose/articles/de0170a13be930 ）。記事の分け方は 2 つ: **量産されて手抜きの記号になったもの**と、**作り手の都合を見る人に押し付けたもの**。どちらも「使う人のことを考え、意図を持って選ぶ。自分で決めた部分を 1 か所でも残す」で避ける。下は ear-to-ear に当てはめた禁止の一覧（N1〜N20）。

| # | しないこと | ear-to-ear での読み替え・いまの状態 |
|---|---|---|
| N1 | 白地に紫〜青のグラデーション、見出しの一部だけのグラデーション文字、白→灰のグラデーション文字 | 面も文字もベタ塗り。青は使わない（濃い緑・黄緑・金・クリーム） |
| N2 | Inter（既定のまま選ばれた書体）、細い書体の英語のキャッチコピー | 書体はシステムの日本語書体。英字の小見出し（NORTH DISTRICT など）は使わない。見出しは短い日本語 |
| N3 | 「✨」付きのピル型のバッジ、「BETA」の星形バッジ | 印は文字だけ（目安・可・済・未確認）。記号・絵文字を付けない |
| N4 | 角丸カードが 3 つ並び、絵文字アイコンと左端・上端の色つきバーを持つ | 「特徴の紹介」のカードは作らない。行の左の色の帯は状態の意味がある所（収穫可能・収穫済）だけ |
| N5 | 「次のレベルへ」「シームレスな体験」などの決まり文句 | 言葉は現場の言葉（目安の畑、刈る順番、未確認）。盛らない（§11） |
| N6 | 黒に近い地に細い方眼線、上からにじむ紫〜青のグロー、`$ npx … init` のようなコマンド風の飾り、Bento グリッド | 地はクリーム、飾りの線・光・疑似コマンドは置かない。大きさ違いのタイルの詰め合わせは作らない |
| N7 | 部品集の背景をそのまま流用して、それらしく見せる | 部品集は入れない（design-concept §2 の分析のとおり） |
| N8 | 全幅の画像スライダー、自動で切り替わるカルーセル | 写真は 1 枚ずつ縦に送る。自動で動くものは無い（P5） |
| N9 | 丸いアイコンが 3 つ並ぶ特徴紹介、ロングシャドウ | アイコンで説明しない（D14）。影は板と下の帯の薄い 1 つだけ |
| N10 | Corporate Memphis（手足の長い紫や青の肌の人物の汎用イラスト） | イラストを置かない。写真と地図だけ |
| N11 | ニューモーフィズム（同じ色の面に明暗 2 つの影） | 押せるものは輪郭と塗りで分ける（§7-7） |
| N12 | ガラス・Liquid Glass（半透明で下が透けて文字が読めない） | 航空写真の上の札は不透明に近い暗い地（.78）＋白文字。透けさせない |
| N13 | 同意のポップアップの乱立、ダークパターン（「すべて同意」だけ大きく、拒否を小さく灰色に） | ポップアップ・モーダルは作らない。合言葉は要るときだけ、同じ大きさのボタンで |
| N14 | 光沢のジェルボタン、濡れた床の反射、ライムグリーン×オレンジ、タグクラウド | ボタンはベタ塗り。黄緑は「収穫可能の塗り」と「選択」の 1 つの意味にだけ使い、オレンジは使わない |
| N15 | 流れる文字（marquee）、アクセスカウンター、「工事中」バナー、Comic Sans、水玉の壁紙、虹色のワードアート | 「準備中」は下の帯の小さな文字だけ。できていない画面を派手に知らせない |
| N16 | 箇条書きの詰め込みで自動縮小された小さな文字、図形に食い込む文字、緑の上の濃い灰色の読めない文字 | 文字は 18px を下げない。緑の面の上は白文字（§3-4 のコントラスト） |
| N17 | 本文の上にとりあえず被せるクリップアート、斜めのワードアートの「がんばろう！」 | 飾りの画像・励ましの文言を置かない |
| N18 | 官公庁のポンチ絵（矢印と枠で全部を 1 枚に詰め、画像化して検索できない） | 引き継ぎメモは文字と引用 [n]。図にして画像化しない |
| N19 | 各部署の要望を全部トップに載せた「調整の産物」 | トップは地図だけ。入口は「写真を送る」と下の帯の 3 つ |
| N20 | 誰も選んでいない構図（色だけ変えた無難な正解） | この文書と試作で決めた「目安の畑を上に固定して縦に送る」「人の判断は面、AI は丸」が、自分で決めた部分 |

当てはめの点検（11-05）: 地図の実装（`feature/l1-map-leaflet`）は N1〜N20 に触れていない。Codex の試作にあった英字の小見出し（N2）とキャッチコピー風の見出し「収穫の気配を、地図から。」（N5 に近い）は、実装では日本語の短い見出しだけにして入れない。`.action-bar` の下地のフェード（送るボタンの帯）は透明→クリームの 1 段で、N1 のグラデーションの面には当たらないが、ベタ塗りに変えてもよい。

## 2. トークンの置き場

- `src/app/globals.css` の `:root` に、**基礎値**（`--palette-*`）と**用途**（`--text-1`、`--fill-ready` など）の 2 段で置く。部品は用途だけを参照する
- 地図の上の値（輪郭・札・丸）は `--map-*`。Leaflet の既定の見た目（`.leaflet-container` のフォント、`.leaflet-control-zoom` の 30px のボタン）は `globals.css` で上書きし、ボタンは 44px 以上に
- 色相を足すときは `--palette-*` に 1 行足して用途から参照する。部品に生の値を書かない

| 選択中 | 輪郭の内側に `--map-selected` 3px、白線は 3px に太る | 行の枠 2px `--brand` | — |
| 未確定の写真あり | 直径 12px の点 `--pending-dot`、縁 1px wheat-700、札の右上 | 「未確定 1 枚」 | — |

### 3-4. 航空写真の上で読む決まり（P4）（→ §0）
- 地図の上の文字は**必ず暗い札の上に白**（`--map-label-bg` の上に `--text-on-dark`、14〜16px 太字）。裸の文字を写真の上に置かない。麦色の札は例外で、麦色の地に `--benchmark-ink`（4.6:1）
- 輪郭は**二重線**: 下に `--map-outline-under` 4px、上に `--map-outline` 2px。明るい畑でも暗い林でも線が見える（3:1 以上を両方の背景で満たす）
- 塗りは不透明度 .45 まで。写真が透けて、塗った後も畑の様子が見える
- 下地は動かさない・暗くしない。ページ側（シート・一覧）はライト固定の白地
- デモの下地（描いた架空の村）は、本番の空中写真に近い明るさ（緑〜黄〜土色）で描く。下地が極端に明るい・暗いとこの決まりの検証にならない

## 7. 操作

### 7-1. 選択の維持（地図・写真・順番で同じ圃場）
- 選んでいる圃場は 1 つ（`selectedFieldId`）。地図の輪郭の強調、シートの見出し、順番の一覧の行の枠が**同じ値**から描かれる
- URL のハッシュ `#A-03` に写す。圃場ページ（`/fields/A-03`）から「地図に戻る」は `/#A-03`。再読み込みで選択が戻る
- 層を切り替えても（シート ↔ 順番の段）選択は消えない。地区を切り替えたときだけ消える（別の地区の畑は選べない）
- 一覧の行を押す → 地図がその輪郭を**中央に寄せる**（拡大率は変えない）。地図の輪郭を押す → 一覧がその行までスクロール

### 7-2. 地図
- 移動: 指 1 本のドラッグ。拡大・縮小: 指 2 本、ホイール、＋－ボタン（44px 以上、`--map-control-bg`）。ダブルタップの拡大は使わない（輪郭のタップと競合する）
- タップの判定: 押してから 8px 以上動いたら移動、動かなければタップ。輪郭の内側のどこを押しても選択。札は押しても同じ圃場を選ぶ
- 拡大率の範囲: 全圃場が入る倍率（既定）〜 1 圃場が画面の半分になる倍率。既定の表示は**選んだ地区の全圃場が入る**位置
- 札は拡大率で位置を変えない（輪郭の重心）。輪郭が小さくて札が重なる倍率では、番号だけの札（「A-03」）にする（名前・判断は省く）。選択中の輪郭の札だけは常に全部出す

### 7-3. シート（3 段）（→ §0）
- 段: **一行**（`--sheet-peek`。見出し＋「目安と比べる」「順番」の入口）／**半分**（`--sheet-half`。写真の 1 段目が見える）／**全画面**（`--sheet-full-top` まで）
- つまみのドラッグ、または見出しのタップで段が変わる。放したときの速さと位置で近い段に吸着（閾値 64px、0.5px/ms）。全画面で下に引くと半分、半分で下に引くと一行。**一行より下には閉じない**（圃場を選んでいる限り何かが見える）。閉じるのは「×」か、地図の何もない所をタップ
- シートの中は縦スクロール。シートが全画面でないときは中をスクロールしない（つまみの操作と競合するため）
- 何も選んでいないとき: シートは出ない。代わりに地図の下に凡例の帯（§12-15）

### 7-4. 並べ替え（順番の段）（→ §0）
- 行の右端の**持ち手**（56×56px、「≡」の文字でなく 3 本の線を CSS で描く）を押して上下に動かす。押した瞬間に行が持ち上がり（枠が青に）、ほかの行が空く。放すと落ちる（150ms）
- 持ち手以外を押すと行の選択（地図が寄る）。長押しは使わない（iOS のメニューと競合）
- キーボード・補助: 行に「上へ」「下へ」のボタン（44px）を持ち手の左に出す（`prefers-reduced-motion` のときと、設定で「ボタンで並べ替え」を選んだとき）
- 動かした瞬間に地図の番号が付け替わる（保存前でも）。未保存の印「保存していません」を段の上に出す。「仮の順を保存」で消える
- 「確定する」は 2 段（§7-5）。確定後に動かすと「確定し直す」に変わる

### 7-5. 取り消し・確定の 2 段
- 1 回目で同じ場所のボタンが「本当に確定する（5 秒で戻ります）」に変わり、5 秒で元に戻る。2 回目で実行。モーダルは出さない（既存 D10）

### 7-6. 結果は押した所の近くに
- 「保存しました」「確定しました」「残しました」は押したボタンの直下に 1 行。トースト・通知は無し。失敗は同じ場所に赤い文字で「何が起きたか。どうするか」

### 7-7. 押せるものの状態
| 状態 | 見え方 |
|---|---|
| 通常 | §12-13 |
| active | `transform: scale(.98)` 100ms |
| focus-visible | `box-shadow: var(--focus-ring)` |
| disabled | `opacity: var(--disabled-opacity)` |
| busy | 不透明度 1 のまま、文字を「保存しています…」に |
| selected（切り替え） | 枠と文字 `--brand`、地 `--brand-soft`、`aria-pressed` |

## 10. アクセシビリティ

- コントラスト: 本文 7:1 目標・最低 4.5:1、札の白文字は暗い地（.78）の上で写真が最も明るい場合でも 4.5:1 以上（検証: 白 `#fff` の下地に .78 の黒を重ねた色はおよそ `#3a3e42`、白文字で 10:1 以上）。輪郭の二重線は 3:1（白線が暗い林の上、黒線が明るい畑の上）

- 状態は文字＋形。収穫済の斜線、仮の破線は色が見分けにくくても分かる
- 並べ替えは持ち手のドラッグのほかに「上へ」「下へ」のボタンで同じことができる
- `prefers-reduced-motion` で動きを 0 に。地図の中央寄せも即時
- 地図の操作（移動・拡大）はキーボードでも: 矢印で移動、＋－で拡大。輪郭は Tab で順に

## 12. 部品

### 12-1. 輪郭（parcel）（→ §0）
- SVG の `<path>`（Leaflet では `L.polygon`）。線は §3-4 の二重線（下 4px 黒 .55、上 2px 白）。塗りは §3-3
- 選択中: 白 3px、内側に青 3px（`stroke` を 2 本重ねる。Leaflet では 2 つの polygon）
- `pointer-events: fill`。輪郭の中のどこでも押せる

### 12-2. 札（map label）（→ §0）
- 輪郭の重心に置く。1〜3 行: 1 行目「A-03 北の3」、2 行目「可 7/21」（判断があるとき）／「未確認」、3 行目なし
- 地 `--map-label-bg`、角 4px、文字 `--text-on-dark` 14px 太字、余白 2px 8px
- 混む倍率では 1 行目の番号だけ（§7-2）。選択中は常に全部
- 札の右上に「未確定の写真あり」の点（§3-3）

### 12-3. 目安の札
- 「目安」の 2 字。地 `--benchmark`、文字と縁 `--benchmark-ink`。輪郭の札の**上**に付く（札と 4px 離す）
- 1 地区に 1 つまで。指定が無ければ出さない。一覧の見出しにも同じ札

### 12-4. 順番の丸（rank）（→ §0）
- 直径 28px（地図）／36px（一覧）。数字 16px 太字
- 仮: 地 `--surface`、縁 2px 破線 `--rank-draft`、数字 `--rank-draft`。確定: 地 `--rank-final-bg`、数字 白
- 地図では札の**左**に付く。情報不足の畑には丸を付けない（「—」も付けない）

### 12-5. シート（→ §0）
- 地 `--background-2`、上の角 16px、上辺 1px `--border-strong`、つまみ 36×4px
- 一行の段の中身: つまみ／見出し行「A-03 北の3 [目安] [可 7/21]」／入口 2 つ「目安と比べる」「順番 ▸」（56px、副ボタン）／「×」（44px、右上）
- 半分・全画面の中身は `screen-spec.md` §2

### 12-6. 比較の 2 列と縦スクロール（→ §0）
- 列は 2 つ、同じ幅（`(100% − 8px) / 2`）。左 **目安の畑**、右 **この畑**。見出しに番号・名前・目安の札。目安が無い地区では左が「比べる相手を選ぶ」のボタン（押すと地図に戻って輪郭を選ぶ）
- 1 段 = 1 つの撮影日。両列に同じ日の写真があれば横に並ぶ。片方に無ければ**空の枠**（「この日の写真はありません」）。日付の違う写真を同じ段に置かない（最も近い日を並べたくなるが、誤解のもと。日付は段の左に 1 行）
- 縦にスクロールすると古い日へ。段の見出し（日付）は `position: sticky`
- 1 列に切り替え（「この畑だけ」）も用意。1 列のときは幅いっぱいの 4:3
- 写真をタップで元の大きさ（新しいタブ。`/api/photo-files/:id`）

### 12-7. 写真の枠と空の枠
- §6-3。枠の下の 1 行: 「7/21・A-03」。試作では「合成」の札

### 12-8. 昨年の枠
- 比較の下に 1 節。見出し「昨年の同じ週」。地 `--surface`、縁 1px `--border-strong`（今年の枠は縁 `--border`。昨年は少し強い縁で区別）、左上に年の札「2025年」（地 `--brand-soft`、文字 `--brand`）
- 中身: 同じ週（撮影日の ±3 日）の写真（目安／この畑の 2 列、今年と同じ並び）、作物、人の判断（あれば「7/22 収穫可能」）、収穫日（あれば「7/24 収穫」、無ければ「収穫日は記録なし」）
- 作物が違う: 写真は出すが見出しに「2025年は大豆（別の作物）」。記録が無い: 枠の中に「2025年の記録はありません」
- 昨年の写真は今年の列に絶対に混ぜない（枠の外に出さない）

### 12-9. 作付けの表示
- シートの見出しの下に 1 行「2026年・小麦」。小麦でない年（輪作）は「2026年・大豆。今年は対象外」と書き、判断のボタンを出さない

### 12-10. 順番の一覧（order list）と `HarvestOrderDraft`（→ §0）
- 1 行 = 1 圃場: 左から 順番の丸（36px）／写真（72×54、最新 1 枚。無ければ空の小枠）／番号・名前・目安の札・判断の札／根拠の 1 行（折りたたみで全文）／持ち手（56px）
- 群は 2 つ: **順位あり**／**情報不足**（見出し「情報不足（順位を付けていません）」、丸なし、何が無いかを 1 行）
- 段の上: 「北地区の収穫順 ・ 記録から並べた仮の順（7/21 15:40 時点）」、未保存の印、ボタン「仮の順を保存」「確定する（委員長）」
- データ（`src/types/` に足す案。共有ファイルなので両方の承認）:
```ts
interface HarvestOrderDraft {
  district: string; season: string;            // "北地区", "2026"
  generatedAt: string; model: string | null;    // null = 人が最初から並べた
  items: { fieldId: string; rank: number | null; // null = 情報不足
           reasons: { text: string; cites: string[] }[];   // cites = 記録の id（StatusEvent / photo）
           missing: ("no_photo_this_season" | "no_status" | "no_last_season" | "no_benchmark")[] }[];
  state: "draft" | "confirmed"; confirmedAt: string | null; confirmedBy: "admin" | null;
}
```

### 12-11. 根拠と足りない情報
- 根拠の文は引用の印 [n] 付き（L6 と同じ形）。[n] を押すと元の記録（判断・写真）がシートの中で開く
- 足りない情報は文の末尾でなく、行の下に別の 1 行「足りない: 今年の写真、判断」（`--text-2`）
- AI が使った記録の範囲を段の下に 1 行「使った記録: 判断 6 件、写真 11 枚、昨年の収穫日 10 件」

### 12-12. 判断の入力
- 既存の L1 の形（切り替えボタン 2 つ、理由の切り替え、メモ 200 字、根拠の写真 5 枚まで、主ボタン「判断を残す」）。シートの比較の**下**に置く。理由の選択肢は `STATUS_REASONS`
- 残した直後に「残しました。順番の仮の順に反映されます」。地図の塗りが即時に変わる

### 12-13. ボタン
- 主: 地 `--brand`、文字 白、56px、角 16px。副: 地 `--surface`、枠 `--border-strong`、文字 `--brand`。危険（確定し直し・取り消しの 2 段目）: 枠と文字 `--assertive`
- 地図の上の操作（＋－、地区、凡例の開閉）: 地 `--map-control-bg`、44px、角 8px、枠 1px `--border-strong`

### 12-14. 上の帯
- 高さ 56px、地 `--surface`、下に 1px `--border`。左「ear-to-ear」（文字。ロゴは 11/6 に決まるまで）、中央「北地区 ▾」（地区の切り替え、56px）、右「写真を送る」（副ボタン）
- 帯は地図の上に重ねず、地図の上に置く（地図の高さから引く）

### 12-15. 凡例
- 何も選んでいないときに地図の下に 1 行（高さ 44px、地 `--map-control-bg`）: 「■ 収穫可能（人の判断） ▨ 収穫済 □ 未確認 ⓵ 仮の順（破線） ❶ 確定 [目安]」。文字で書く（記号は CSS で描く）。押すと説明が開く
