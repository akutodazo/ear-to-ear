# デモの通し方（動画と審査員向け）

画面を 1 本の流れで見せる手順。LINE のお知らせを 2 人で見せる台本は `docs/dev/line.md` §5。データはすべて架空（K10）。

## 開く URL には `?today=2026-07-20` を付ける
- 5 段目「来年の引き継ぎ」は、**昨年の判断の日の前後 7 日だけ**出る（合格条件 16）。デモの記録は 7 月なので、11 月にふつうに開くと何も出ない
- URL の最後に `?today=2026-07-20` を付けると、今日を 7/20 として見せる。下の帯の上に「7/20 として表示中（デモ）×」が出る。同じタブの中では画面を移っても続き、× で外れる
- README・動画の説明・審査員に渡す URL には、`?today=2026-07-20` を付けたものを書く（例: `https://<demo の URL>/?today=2026-07-20`）
- **demo に入れる架空の記録（#130）も 7 月の日付にする**。判断の日が 11 月だと、「昨年の同じ頃」に「今年 11/5 に収穫可能」と出て、7/20 として見せる昨年の引き継ぎと噛み合わない（11-06 の dev では A-01 の判断が 11/5 だった）

## 流れ（スマートフォンの幅、3〜4 分）
| 順 | 画面 | 見せること |
|---|---|---|
| 1 | 地図 `/?today=2026-07-20` | 空中写真の上の区画。黄緑＝収穫可能、目安の畑は金の輪郭。北の 3 を押すと板に最新の写真と判断、「昨年の引き継ぎ（2025年）あり ›」 |
| 2 | 見比べる `/fields/A-03` | 「同じ日に撮った別の畑と」で目安と並べ、境目を指で動かす。「この畑の前の日と」で同じ畑の推移 |
| 3 | 判断を残す | 収穫可能と理由（穂の色・黄色い穂の割合）、根拠の写真を選んで記録。地図の塗りが変わる（LINE のお知らせは `line.md` §5） |
| 4 | 昨年の同じ頃 | 昨年と今年を同じ形で並べる（日数の差は言わない）。「昨年の引き継ぎを読む（2025年）」を開く。出所は年つきの灰色の字 |
| 5 | 今年の引き継ぎメモ | 管理者で「メモを作る」（**実家の写真が無い畑だけ**。下の注意）。Claude が記録だけを引用して書き、文ごとの根拠の印を押すと判断の履歴に戻る。根拠の無い文は「根拠なし」 |
| 6 | 刈る順番 `/order` | 記録からの下書き（今年「収穫可能」と判断した畑だけに順位）。行を長押しして並べ替え、委員長が 2 段で確定 |
| 7 | LINE に 1 枚 | 「送る準備」→「LINE で送る」。トークに地図のサムネイルが出る |

## 前もって確かめること
- **実家の写真がある畑では「メモを作る」を押さない**。写真そのものは送らないが、写真の撮影日などの記録の文が Claude に渡る。K10・privacy.md は「実在の農家の写真・記録を Claude API に送らない」。メモを作るのは、合成の写真（`node scripts/make-fixtures.mjs`）か写真の無い畑だけにする（11-06 本人決定。dev の A-03 の写真は実家のもの）
- 5 の「メモを作る」は Claude の 1 日の回数（50 回）を使う。撮る前に 1 回作っておき、撮るときは作り直さなくても見せられるようにする
- 管理者の合言葉が要る画面（判断を残す・メモを作る・確定）は、撮る前に入っておく。合言葉を画面に映さない
- 写真は架空のものか、決定（`docs/decisions.md` 11-04 夜）で認めた範囲のものだけ。撮影位置は端末の外に出ない（K6）
