# 公開範囲

**守る対象は「正確な撮影位置」**。候補の番号から大まかな場所が分かることは許容する（K6）。閲覧は合言葉なしなので、URL を知る人は誰でも見られる。だからデータは全部架空（K10）。

| 情報 | 端末の中 | サーバーに送る | D1・R2 に残る | 画面に出る |
|---|---|---|---|---|
| 撮影位置（XMP/EXIF の座標） | 読む | **送らない** | **残らない** | 出さない |
| 候補の畑までの距離 | 計算する | **送らない** | **残らない** | 送る前の画面にだけ出す |
| 候補の番号（近い順、最大3） | 計算する | 送る | 残る | 「未確定（推定 A-03）」 |
| 圃場の位置（地図のピン） | — | 架空データとしてリポジトリに入っている | — | 出る |
| 写真 | 長辺1600pxに縮小・再エンコード（メタデータ消去） | 縮小後だけ | R2（非公開、Worker 経由で配信） | 出る |
| 元ファイルのハッシュ | 計算する | 送る | 残る（二重登録の判定） | 出さない |
| 送った端末 | Cookie の端末 ID | 送る | 残る | 画面には出さない。ただし新着の一覧（`GET /api/photos/recent`、合言葉なし）の本文には端末 ID が載る（T21、11-03 先輩決定・本人承認、PR #75）。判断を残した端末 ID も、地図の一覧（`GET /api/fields/summary` の `latest`、T24）と圃場ごとの判断の履歴（`GET /api/fields/:id/status-events`、T26）の本文に載る（どちらも合言葉なし。11-04 本人の案・先輩決定、#99）。端末 ID は Cookie を発行するたびに作る乱数で、名前・端末の種類は分からないが、同じ端末の写真をまとめてたどれる |
| 判断の理由・メモ・根拠の写真 | — | 送る | 残る | 出る |
| 合言葉 | 入力 | 送る（HTTPS） | **残らない**（Secret と照合するだけ） | 伏せ字 |
| IP アドレス | — | 届く | **生では残らない**（失敗回数は塩つきハッシュで数える） | 出さない |
| LINE のグループ ID／個人 ID | — | Webhook で届く | グループ ID だけ残す。個人 ID は残さない | 出さない |
| LINE から届く写真（L9、#172） | 委員が LINE のグループに送る（LINE が縮める・メタデータを消すかは未確認） | サーバーが LINE から取りに行く（登録したグループの画像だけ） | APP1〜15 を**読まずに消して**から R2 に置く（撮影位置・撮影日は残らない。候補の番号も無い）。二重の判定に取ってきたままのバイト列のハッシュを残す。送った人の LINE の個人 ID は残さない（送った端末は `line` の 1 つ） | 新着に「未確定」で出る。LINE の会社のサーバーにも写真が残るので、架空のグループの中だけで使う |
| 刈る順番の絵と順（LINE に 1 枚、#159〜#162） | canvas で描く（区画・番号・順・地理院タイル。撮影位置は描かない） | 「送る準備」で絵（JPEG）と番号の並びだけ送る | R2 `shares/` と D1 `order_shares` に 60 日。送った端末 ID も残す | 共有の URL（`/api/shares/<id>`、合言葉なし）を知る人は誰でも見られる。LINE のサーバーが取りに来てサムネイルを作る。端末 ID は出さない |

- Worker は公開側の画像に APP1〜APP15 が無いことを検査する
- 位置情報の座標を画面に表示する機能は作らない
- 実在の農家の写真・記録は Claude API に送らない
