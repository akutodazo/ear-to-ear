## 指摘（重い順）

### #1 上の段が画面の 63% を固定で占め、下に残るのは 185px — 直す
- **どこ**: `src/app/fields/[id]/field-client.tsx` の `.stage`（上の段、高さ 510px、送っても動かない）と `.compare-body`（送れる範囲）。`src/app/globals.css` の末尾
- **何が問題か**: 812px の画面で、上の帯 56px＋上の段 510px（札の段 152px＋写真 357px）＋下の帯 61px。この畑の名前・判断・写真の流れ・昨年・履歴は、残りの 185px の窓で送ることになる。開いた直後に見えるのは「A-04 北の4」と「7/22 に収穫可能と判断」の 2 行だけ。「判断を残す」を開くと上の段は 364px に縮むが、記録の帯（69px）が増えるので、窓は 262px。高さ 363px の入力は窓に収まらない
- **なぜ**: REVIEW-BRIEF §5「スマートフォンの実画面で、文字・写真・タップ範囲が無理なく使えるか」、§3「畑の選択 → 最新写真 → 比較・収穫順へ、対象を見失わずに進める」。比べた後に判断へ進む所が狭くなっている
- **直し方の案**: 上の段全体を固定するのをやめ、送ると札の段は流れ去り、写真（2 枚の重ね）だけが上に残る形にする。または、写真を送り始めたら上の段を半分の高さに縮める。札の段は、比べ方を 1 段にまとめて減らす（#2）

### #2 畑を選ぶ札の段が 2 つ、同じ見た目で並ぶ。上は番号、下は名前 — 直す
- **どこ**: `src/components/compare/field-switcher.tsx`（上の帯の「A-01 A-02 □A-03 A-04」。この畑を切り替える）と `src/components/compare/compare-controls.tsx` の相手の段（「上に 北の1 北の2 □北の3」。上の写真の畑を切り替える）
- **何が問題か**: どちらも同じ丸い札で、同じ地区の同じ畑が並び、目安には同じ金の印が付く。違うのは、上が番号・下が名前であることと、下の段の頭の小さな「上に」（14px）だけ。上の帯の「A-03」を押すと見ている畑そのものが変わり、相手の段の「北の3」を押すと上の写真だけが変わるが、見た目からは区別できない。番号と名前が段ごとに違うので、「A-03」と「北の3」が同じ畑だと結ぶのにも一手間かかる
- **なぜ**: REVIEW-BRIEF §5「どこがタップできるのか、自然に分かるか」、§3「名前・番号は識別のため」（同じ畑を同じ言い方で）。依頼の問い「上下どちらが『この畑』かを見失わないか」にも響く
- **直し方の案**: 相手の段は札にせず、上の写真の帯（「目安 A-03 北の3」）を押すと相手を選ぶ一覧が開く形にする（相手を変えるのは上の写真に対する操作なので、写真の上に置く）。札で残すなら、番号と名前を両方の段でそろえ（「A-03 北の3」）、相手の段は写真の上端に重ねて「上の写真の相手」だと位置で分かるようにする

### #3 「この畑の前の日と」で、選んだ日が一番古い日だと、上に新しい日が出る。2 段の日付の札の意味が分からない — 直す
- **どこ**: `src/services/photo-compare.ts` の `resolveSameField`（前の日が無いと `earlierOptions[0]` に落ちる）、`compare-controls.tsx` の撮影日の段（見出しなし）と「上に」の日付の段
- **何が問題か**: 「同じ日の別の畑と」で 7/10 を選んでから「この畑の前の日と」に切り替えると、下が 7/10、上が 7/19 になった。名前は「前の日と」なのに上は後の日。撮影日の札は 2 つの比べ方で共有されているので、この組み合わせは普通に起きる。また、日付の札が 2 段（「7/19 7/10」と「上に 7/10」）並び、1 段目に見出しが無いので、1 段目が「下の写真の日」だと読み取れない
- **なぜ**: 依頼の問い「2 つの比べ方の意味が、札の文字とアイコンから読めるか」。REVIEW-BRIEF §3「選択後もどの場所を見ているか分かる」
- **直し方の案**: 「この畑の前の日と」では、上は必ず選んだ日より前の日にする。前の日が無ければ、下を最新の日に戻すか、「前の日の写真はありません」と言う。日付の段は 1 段にし、2 つの日を両端の札（例「7/10 ↔ 7/19」）で選ぶ。または 1 段目の頭に「下に」を付けて「上に」と対にする

### #4 違う畑の 2 枚を境目で重ねると、上は上の写真の空と遠く、下は下の写真の手前しか見えない — 直す
- **どこ**: `src/components/compare/split-viewer.tsx`（2 枚とも同じ枠に `object-fit: cover` で置き、上の写真を `clip-path` で切る）
- **何が問題か**: 境目を真ん中にすると、上には A-03 の写真の上半分（空と遠くの畑）、下には A-04 の写真の下半分（手前の穂）が出る。違う畑・違う立ち位置で撮った写真は位置がそろわないので、同じ所を比べることにならない。両方の穂の色を見るには、境目を上下いっぱいに往復させるしかなく、2 枚の同じ所を同時に見る瞬間が無い。重ねて境目をずらす見せ方は、同じ位置から撮った前後の写真（「この畑の前の日と」）には向くが、違う畑どうしには向きにくい
- **なぜ**: REVIEW-BRIEF §1「地図・畑・写真の関係の見せ方から新しさを作る」、§4「目安の畑と、ほかの畑の違いを見て、収穫時期と仮の順番を考える」。見比べの中心の操作なので、比べたい部分（穂の色・黄色い穂の割合）が同時に見えることが要る
- **直し方の案**: 上下の 2 つの窓に、それぞれの写真の真ん中を出す形にする（`clip-path` ではなく、2 つの枠の高さを境目で配分する。境目を動かすと片方が広がる）。境目の操作はそのまま使える。「この畑の前の日と」は今の重ね方のままでもよい

### #5 相手の札が薄くなる理由が、スマートフォンでは分からない — 直す
- **どこ**: `compare-controls.tsx` の相手の札（`disabled` と `title="この日の写真がありません"`）
- **何が問題か**: 7/10 に切り替えると「北の2」が薄く（不透明度 0.4）なって押せなくなる。理由は `title`（指を載せたときの説明）にしか無く、スマートフォンでは見られない。「同じ日の別の畑と」という言葉と、日付の札と、薄い札の 3 つを結べば分かるが、多くの人は「この畑は壊れている」と読む
- **なぜ**: 依頼の問い「『同じ日だけ比べる』という決まりが、相手の札の無効化から伝わるか」→ 伝わりにくい。REVIEW-BRIEF §3「文字のメニューだけに機能の意味を背負わせない」
- **直し方の案**: 相手の段の頭を「上に」から「7/10 に撮った畑」に変える（日付が変わると見出しも変わる）。決まりを文の説明にせず、見出しの日付で言う。写真が無い畑は札を薄くするより、段から外す（「この日に撮った畑は A-04 だけ」の時は段ごと消し、上の段の空の表示で言う。いまの空の表示「この日に写真がある畑は、この畑だけです」は良い）

### #6 読み込みに失敗しても、上の段は「この畑の写真はまだありません」と言う。写真が無い畑では同じ文が 2 回出る — 直す
- **どこ**: `field-client.tsx` の `stageNote`（`district.loading` が false で `bottom` が null なら、失敗でも「まだありません」）、写真の流れの空の表示
- **何が問題か**: 読み込みに失敗した A-04 で、上の段は「この畑の写真はまだありません」＋「もう一度読み込む」、下の写真の流れは「読み込めませんでした…」と、同じ畑について違うことを言った。A-09（本当に写真が無い）では、上の段の「この畑の写真はまだありません」と、下の「まだ確定した写真はありません」＋「写真を送る」が上下に並び、使えない比べ方の 2 つの札も出たまま
- **なぜ**: 写真が無いのか、通信の問題なのかを取り違えると、委員は写真を送り直してしまう。REVIEW-BRIEF §2「見るより読む」
- **直し方の案**: 失敗のときは「写真を読み込めませんでした」と言う（`district.failed` を見て分ける）。この畑の写真が 1 枚も無いときは、上の段（比べ方の札と空の枠）ごと出さず、下の「写真を送る」だけにする

### #7 上下どちらが「この畑」かは、名前を読まないと分からない — 提案
- **どこ**: `split-viewer.tsx` の帯（上「目安 A-03 北の3」、下「A-04 北の4」）
- **何が問題か**: 下の写真のすぐ下に「A-04 北の4」の見出しがあるので、位置で「下がこの畑」と読める。見失うほどではない。ただ「この畑の前の日と」では上下とも「A-04 北の4」で、違いは日付だけになり、どちらが新しいかは日付を読み比べる必要がある
- **直し方の案**: 下（この畑・選んだ日）の帯の地を少し濃くするか、左端に細い色の線を付け、上下で帯の見た目を変える。「前の日と」では上の帯の日付の前に「前」の印（左向きの矢印など）を添える

### #8 札の高さが 40px — 提案
- **どこ**: 撮影日・相手の札（`.chip`）、写真の下の「根拠にする」
- **何が問題か**: 比べ方の札・上の帯の札・持ち手は 44px あるが、撮影日と相手の札、「根拠にする」は 40px。spec §7「ボタンは押しやすく（手袋を想定）」
- **直し方の案**: 44px にそろえる（#1 で段を減らせば、高さを足す余裕もできる）

### #9 境目を端まで動かすと、下の写真の帯が持ち手に重なる。重ねの真下の写真の流れが 3 枚目の重ねに見える — 提案
- **どこ**: `split-viewer.tsx` の `.split-caption-bottom`、`.stage` と `.compare-body` の境
- **何が問題か**: 境目を下の端（88%）まで動かすと、下の写真の帯（「A-04 北の4 2026年7月19日」）が持ち手の線と重なる。また、写真の流れを送ると、重ねの真下に同じ形の帯付きの写真が来て、重ねの続きに見える
- **直し方の案**: 下の帯は、下の写真の見えている範囲が帯より狭くなったら隠す。上の段の下端に影か区切りの線を付け、送れる範囲と分ける

## 依頼の問いへの答え
| 問い | 答え | 根拠（実画面） |
|---|---|---|
| 2 つの比べ方の意味が、札の文字とアイコンから読めるか | **比べ方の札は読める。その下の札の段は読みにくい** | 「同じ日の別の畑と」（畑が並ぶアイコン）と「この畑の前の日と」（暦のアイコン）は、文字で意味が分かる。ただ、その下の撮影日の段には見出しが無く、相手の段は上の帯の畑の札と同じ見た目（#2）。「前の日と」で上に後の日が出る組み合わせがある（#3） |
| 上下どちらが「この畑」かを見失わないか | **おおむね見失わない** | 下の写真の帯と、そのすぐ下の見出しがどちらも「A-04 北の4」で、位置で結べる。上の帯は「目安」と金の印付き。「前の日と」では上下とも同じ名前で、日付だけが違う（#7） |
| 境目の持ち手は指で使えるか（44px） | **使える** | 丸い持ち手は 44×44px、押せる範囲は幅いっぱい×高さ 48px。実際に指でつかむ操作（押して動かす）で 50% → 88% に動いた。12〜88% で止まるので、どちらかが見えなくなることも無い。ただし違う畑どうしでは、境目を動かしても同じ所は比べられない（#4） |
| 「同じ日だけ比べる」が相手の札の無効化から伝わるか | **伝わりにくい** | 7/10 にすると「北の2」が薄くなるが、理由は指を載せたときの説明だけ（#5） |
| 前回 #1（地図に戻ると北地区）は狙いどおりか | **直った** | 見比べるの A-09 から「地図」で戻ると、地区の欄は南地区、地図も南地区に合わさり、A-09 の白い太線が板の上に見えた |
| 前回 #2（日数の差）は狙いどおりか | **直った** | 「昨年 7/25 に収穫可能と判断、7/29 に収穫済／今年 まだ判断はありません」のように、昨年と今年を同じ形で並べ、差は書いていない |
| 前回 #3（写真の帯）は狙いどおりか | **直った** | 写真の流れの各写真の下端に「A-04 北の4 2026年7月10日」の帯が付き、送っても畑と日付が分かる。重ねの帯と同じ形（#9 の副作用あり） |
| 前回 #4（記録するの帯）は狙いどおりか | **直った。ただ窓が狭い** | 「やめる／記録する 根拠 0 枚」が下の帯の上に固定され、どこまで送っても押せる。説明の文は消えた。入力を開くと送れる範囲は 262px（#1） |
| 前回 #5（写真を送る）は狙いどおりか | **一部** | 写真の無い A-09 に「写真を送る」（カメラのアイコン付き）が出て、中身の無い判断の履歴の段は畳まれた。上の段は使えない比べ方の札と「この畑の写真はまだありません」を出したまま（#6） |
| 文字だけで説明している所が残っていないか | **2 か所** | 相手が無いときの「この日に写真がある畑は、この畑だけです」「この畑の写真は 1 日分だけです」（言い方は良いが、上の段の大きな空の枠に文だけ）。写真が無い畑の上の段（#6） |

## 良い点
- 2 枚を重ねて境目を指で動かす形は、写真が主役で、文字や数字が少ない。境目の白い線と丸い持ち手は、見ただけで「動かせる」と分かる
- 相手の既定が目安の畑で、開いた直後に「目安と比べる」が出来ている。目安の帯には金の印と「目安」の文字
- 「同じ日の別の畑と」は日をまたいで比べない、という決まり自体が良い（日が過ぎれば育つのは当たり前、という考え）
- 「判断を残す」を開くと上の段が自動で低くなり、記録の帯が下に出る。前回の往復の問題は解けている
- 昨年と今年が同じ形の 2 行で並び、予想に読める文が無くなった
- 地図に戻ったとき、選んだ畑の地区に合わさるようになった
