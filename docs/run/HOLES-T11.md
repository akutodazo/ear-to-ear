# T11 の穴の記録（docs/dev/holes.md の手順）

破り役は別のセッション（Claude Sonnet、`claude -p`）。渡したのはテストと条項の一覧だけ。組み込みの道具を全部外し、書けるのは `migrations/0001_init.sql` だけ。破り実装はコミットしていない。

| 回 | テスト | 破れた条項 | 主な破り方 |
|---|---|---|---|
| 1 | 32 件 | 11 条項のうち 8（費用 $0.37） | CHECK に値を足す／`UNIQUE(content_hash, uploader_device)`／`UNIQUE` で主キーの代わり／**`sqlitex_photo_geo` という表で撮影位置の検査をすり抜ける**（`NOT LIKE 'sqlite_%'` の `_` は任意の1文字）／トリガー・ビュー |
| 2 | 45 件 | 11 条項のうち 10（費用 $0.28） | `COLLATE NOCASE`／部分索引／親の `COLLATE RTRIM`／既定値を日付で変える／**主キーの NULL**／TEMP の表・ビュー・トリガー |
| 3 | 48 件 | 試していない | 下のとおり、仕組みで止めた |

## 対応
| 穴 | 対応 |
|---|---|
| 検査をすり抜ける表（K6・K16） | テストの補助関数を直した（`sqlite_sequence` だけを名前で除く。生成列も見る） |
| 値・一意・外部キーの形 | テストを足した |
| **SQLite の TEXT の主キーは NULL を許す** | **spec の穴**。spec を直した（`PRIMARY KEY NOT NULL`） |
| 足し算の手口（COLLATE・部分索引・TEMP など） | 個別に追わない。**マイグレーションが spec の SQL と一致するテスト**を足した。条項を増やす代わりに、正本との差をなくす |

## 受容する穴
- spec の SQL そのものの誤りは、一致のテストでは見つからない。意味のテスト（CHECK・UNIQUE・外部キー）で見る

## 気付いたこと
- 2回目の破り役は「個別のテストでは追い切れない」ことを示した。条項ごとにテストを足すより、正本との一致で止める方が短い
- 宣言的な成果物（SQL・設定）は、この形が使える。手続きの実装には使えない
