## 見つかったこと
1. **iOS 26.3.1 の Safari が、ページを開くと約 4 回に 3 回、真っ白で固まる**（「問題が起きたため、このWebページが再読み込みされました」も出る）。クラッシュのログでは、毎回 Safari の JavaScript エンジン（JavaScriptCore の DFG という最適化コンパイラ）の中で落ちている。iOS 18.5 では 5 画面を続けて開いても起きなかった。ホストが macOS 27.2（ベータ）で、シミュレータの iOS 26.3.1 とそろっていない組み合わせなので、**アプリの不具合とは言えない。実機では未確認**
2. **日本語が「?」の枠で表示される**: #133・#134 で直した。直した後は両方の iOS で読める。なお #133・#134 は、環境を「iOS 27 ベータ版のシミュレータ」と書いていたが、実際は **iOS 26.3.1**（このファイルで訂正し、issue・PR・コードのコメントも直した）。実機でも起きるかは未確認のまま
3. **判断を残す画面で、上の見比べエリアが画面の 1/3 近くを占める**。入力欄が狭く、キーボードが出るとさらに狭く感じる。操作はできた
4. **メモ欄に英字を入れると、日本語キーボードの変換候補になる**。今回は「memo」だけが残った。仕様かどうかは決めていない
5. **根拠の写真が 0 枚でも「記録する」が押せた**。仕様どおりか未確認
